# Heat Rush 2.0 - Source Code Export

## Part 1: Project Overview & Setup

### Recommendations for the Developer
1. Install **Node.js** (v18+) and **npm/pnpm**.
2. Run `npm install` or `pnpm install` in the project root to install dependencies.
3. Configure the Supabase instance using the SQL files and edge functions (see Part 4).
4. Create a `.env` file at the root with `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
5. Run `npm run dev` to start the development server.
6. Run `npm run build` to build for production.
